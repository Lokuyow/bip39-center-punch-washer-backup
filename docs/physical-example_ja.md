# 実物例

紙治具をワッシャーへ固定し、打刻してからボルトでまとめるまでの実物例です。

## 1. 打刻後の紙治具

![ワッシャーへマスキングテープで固定し打刻した後の Washer Punch39 紙治具](../images/photos/washer-punch39-jig-after-punching.jpg)

この写真は、実寸で印刷した紙治具をワッシャーへ**マスキングテープで固定し、必要な候補点を自動センターポンチで紙の上から打刻した後**の状態です。紙に見える穴や打痕は打刻によってできたもので、単に印刷しただけの未使用の紙治具ではありません。

## 2. ワッシャーへの固定

![ワッシャーに位置合わせした Washer Punch39 紙治具](../images/photos/washer-punch39-jig-alignment.jpg)

位置合わせした紙治具が打刻中にずれないよう、ワッシャーをマスキングテープで紙治具へ固定します。その状態で必要な候補点を紙の上から直接打刻します。

## 3. 打刻後のワッシャー

![打刻後の Washer Punch39 ワッシャー](../images/photos/washer-punch39-punched-washer.jpg)

紙治具を外したあと、ワッシャー面の打刻位置を目視で確認します。

## 4. 組み上げ例

![ボルトとナットでまとめた Washer Punch39 のワッシャー](../images/photos/washer-punch39-assembled-stack.jpg)

現在のリファレンス実装では、ワッシャーをボルトへ通し、ナットでまとめて保管できます。
