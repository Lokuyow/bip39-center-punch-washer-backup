# 加熱・急冷試験

[English](fire-test.md)

このページは、センターポンチで打刻したステンレスワッシャーに対して行った**補足的な加熱・急冷試験**の記録です。

この試験は規格に基づく耐火試験ではなく、Washer Punch39 の耐火性能を保証するものではありません。主な確認対象は、強い加熱と急冷を受けたあとでも**センターポンチの点状打刻が潰れたり消えたりせず、目視できる状態で残るか**です。

## 試験片について

今回の写真に写っている評価対象の打刻パターンは、現在の4点式点字数字ではなく、開発初期に検討していた**旧11bit方式**で作成したものです。

そのため、この試験は現在の符号化方式そのものを検証するものではありません。ただし、現行方式もセンターポンチによる点状打刻を使うため、打刻跡の物理的な残存性を見る参考資料として掲載しています。

試験開始時、評価対象のワッシャーは未加熱のものを使用しました。一方、固定に使用した**ボルト、ナット、および評価対象以外のワッシャーは、以前の加熱実験ですでに加熱された部品を再利用**しています。

![加熱前の評価対象ワッシャーを含む試験組立](../images/photos/fire-test/fire-test-new-washer-before-heating.jpg)

## 試験手順

1. ガス火で **20分間** 加熱する。
2. 水に入れて急冷する。
3. 再度ガス火で **20分間** 加熱する。

## 観察結果

写真上では、加熱による変色は大きいものの、**センターポンチによる点状の凹みは明瞭に残っています**。

少なくとも今回の試験範囲では、打刻が潰れて点同士の区別ができなくなったり、打刻跡が消えて読み取り不能になったりするような変形は確認できません。旧11bit方式の打刻パターンも、試験後の写真から目視で追える状態に見えます。

したがって、この試験では「加熱 → 水による急冷 → 再加熱」という条件を経ても、センターポンチによる打刻跡そのものは目視可能な状態で残りました。

## この結果の扱い

この結果から、Washer Punch39 全体について特定温度・特定時間の耐火性能を保証することはできません。

また、試験片は現在の4点式点字数字ではなく旧11bit方式なので、現行の符号化レイアウトを直接検証した結果でもありません。

このページは、**センターポンチによる打刻跡が強い加熱と急冷のあとにも残った実物例**としての補足資料です。実際のバックアップについては、火災環境、加熱時間、冷却方法、腐食、機械的損傷など別の条件でも結果が変わる可能性があります。
