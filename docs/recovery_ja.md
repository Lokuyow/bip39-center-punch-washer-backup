# 復元ガイド

[English](recovery.md)

このガイドは、現在の12単語BIP39 Englishリファレンス形式の復元手順を説明します。

## 始める前に

早見表を使って、次を確認してください。

- 開始兼SETの読み方
- 数字の点字パターン
- 1始まりのBIP39番号
- mod 10によるCHECK確認

実際のバックアップを復元するときは、記憶だけに頼らないでください。

## ワッシャー片面を読む

1. 読みたい面を自分に向ける。
2. 開始兼SETを探す。中心の放射線上に上下2つの固定点があり、その間にSET候補点がある。
3. SETを判定する。
   - 右SETだけ = A
   - 左SETだけ = B
   - 左右両方 / どちらもなし = 現行標準では予約または無効。先に原因を確認する
4. 開始兼SETから時計回りに読む。
5. 語順2桁（`01`〜`12`）を読む。
6. BIP39番号4桁（`0001`〜`2048`）を読む。
7. 最後のCHECK 1桁を読む。

## CHECKを確認する

BIP39番号4桁とCHECKをすべて足します。

合計が10で割り切れる必要があります。

例：

```text
2048 / CHECK 6
2 + 0 + 4 + 8 + 6 = 20
```

CHECKが一致しない場合：

- 点字パターンをもう一度確認する
- 腐食、傷、浅い打刻、誤認しやすい跡がないか確認する
- 裏面や他のワッシャーと比較し、文脈上の手掛かりを確認する
- 推測で数字を置き換えない

CHECKは誤り検出用であり、誤り訂正用ではありません。

## 番号を単語へ変換する

本プロジェクトの1始まりBIP39 English表を使います。

```text
0001 = abandon
0002 = ability
...
2048 = zoo
```

本プロジェクトの番号は1始まりです。BIP39ソフトウェア内部で使われる0始まりの実装indexと混同しないでください。

## 全単語を復元する

1. すべてのワッシャー面を読む。
2. 語順で並べる。
3. 各BIP39番号をEnglish単語へ変換する。
4. 完成した単語列全体を確認する。
5. 資金移動やバックアップとして依存する前に、復元したニーモニックを独立した方法で検証する。

独立した確認方法としては、BIP39チェックサムや、既知の非秘密情報であるウォレットフィンガープリント、以前記録した受取アドレスなどを利用できます。

## 裏面の読み方

各面は独立して読みます。

裏面を読む場合は、裏面を自分に向け、その面の開始兼SETから再び時計回りに読みます。表面の配置を頭の中で鏡像反転して解釈しないでください。

## セキュリティ上の注意

ワッシャーにはニーモニックが符号化されていますが、暗号化はされていません。必要なすべての面を正しく読める人は、ニーモニックを復元できます。
