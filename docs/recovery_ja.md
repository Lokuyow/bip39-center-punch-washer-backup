# 復元ガイド

[English](recovery.md)

このガイドは、**Washer Punch39 format v1** の現在の12単語BIP39 Englishリファレンス形式の復元手順を説明します。

## 始める前に

使用しているバックアップが **Washer Punch39 v1** であることを確認し、v1の早見表・仕様・ワードリストを使ってください。

早見表を使って、次を確認してください。

- 開始兼SETの読み方
- 数字の点字パターン
- 1始まりのBIP39番号
- mod 10によるCHECK確認

実際のバックアップを復元するときは、記憶だけに頼らないでください。

## 7枚のリファレンス構成

現在の12単語リファレンス構成では、7枚のワッシャーを使用します。1枚目と7枚目は片面だけに打刻し、2〜6枚目は両面に打刻します。

ボルトに組み付けるときは、1枚目と7枚目の意図的に何も刻印していない面を外側へ向け、外から打刻が直接見えないようにします。

復元時、この2つの外側無刻印面をデータ欠落と判断しないでください。リファレンス構成には、合計12の打刻面があります。

7枚という積み方自体は任意です。製作者によっては別の物理構成を採用している場合があります。

## SET A / B

SET A / B は、**複数のニーモニックを保存する場合にそれぞれを区別する識別子**です。1つのニーモニックをA/Bへ分割する方式ではありません。

同一ニーモニックの各面は同じSETを使用します。複数のニーモニックが混在している場合は、まずSETごとに分けてから、それぞれのSET内で語順を復元します。

## ワッシャー片面を読む

1. 読みたい打刻面を自分に向ける。
2. 開始兼SETを探す。中心の放射線上に上下2つの固定点があり、その間にSET候補点がある。
3. SETを判定する。
   - 右SETだけ = A
   - 左SETだけ = B
   - 左右両方 / どちらもなし = 現行標準では予約または無効。先に原因を確認する
4. 開始兼SETから時計回りに読む。
5. 語順2桁（`01`〜`12`）を読む。
6. BIP39番号4桁（`0001`〜`2048`）を読む。
7. 最後のCHECK 1桁を読む。

## CHECKを確認する

BIP39番号4桁とCHECKをすべて足します。

合計が10で割り切れる必要があります。

例：

```text
2048 / CHECK 6
2 + 0 + 4 + 8 + 6 = 20
```

CHECKが一致しない場合：

- 点字パターンをもう一度確認する
- 腐食、傷、浅い打刻、誤認しやすい跡がないか確認する
- 反対側の打刻面や他のワッシャーと比較し、文脈上の手掛かりを確認する
- 推測で数字を置き換えない

CHECKは誤り検出用であり、誤り訂正用ではありません。

## 番号を単語へ変換する

本プロジェクトの1始まりBIP39 English表を使います。

```text
0001 = abandon
0002 = ability
...
2048 = zoo
```

本プロジェクトの番号は1始まりです。BIP39ソフトウェア内部で使われる0始まりの実装indexと混同しないでください。

## 全単語を復元する

1. すべての打刻面を読む。
2. 複数のSETがある場合はSETごとに分ける。
3. 各SET内で語順 `01`〜`12` に並べる。
4. 各BIP39番号をEnglish単語へ変換する。
5. 完成した単語列全体を確認する。
6. 資金移動やバックアップとして依存する前に、復元したニーモニックを独立した方法で検証する。

独立した確認方法としては、BIP39チェックサムや、**必要なBIP39パスフレーズを含むウォレット条件が分かっている場合**のウォレットフィンガープリント、以前記録した受取アドレスなどを利用できます。

## BIP39パスフレーズ

Washer Punch39 format v1 が保存するのは **BIP39ニーモニック**です。BIP39パスフレーズはワッシャーには保存されません。

パスフレーズを使用していたウォレットを復元するには、そのパスフレーズも別途必要です。ニーモニックだけが正しく復元できても、異なるパスフレーズを使えば別のウォレットになります。

## 裏面の読み方

各打刻面は独立して読みます。

裏側に打刻がある場合は、その面を自分に向け、その面の開始兼SETから再び時計回りに読みます。表面の配置を頭の中で鏡像反転して解釈しないでください。

7枚のリファレンス構成では、外側の2つの無刻印面には符号化されたデータはありません。

## セキュリティ上の注意

ワッシャーにはニーモニックが符号化されていますが、暗号化はされていません。必要なすべての面を正しく読める人は、ニーモニックを復元できます。

外側の無刻印面は、ワッシャーを組み上げた状態で打刻を外から直接見えにくくするだけであり、セキュリティ境界ではありません。
