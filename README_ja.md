# Washer Punch39

**BIP39 Center-Punch Washer Backup**

ステンレスワッシャーとセンターポンチを使って、BIP39 Englishニーモニックを金属へ記録するDIYバックアップ方式です。

![Washer Punch39 紙治具イメージ](images/washer-punch39-jig-preview.png)

1面に1単語を、BIP39単語番号の10進4桁と4点式の点字数字で記録します。実寸の紙治具をワッシャーへ重ね、その上からセンターポンチで直接打刻します。

> **状態:** 実験中 / 開発中です。仕様・印刷寸法・打刻方法・復元手順を独立に検証するまでは、実資金の唯一のバックアップとして使用しないでください。

## 目的

- 安価で入手しやすいステンレスワッシャーを使う
- 専用ソフトウェアなしでも、印刷資料だけで復元できるようにする
- ワッシャーがバラバラになっても語順を復元できるようにする
- 開始位置を視覚的に識別できるようにする
- 紙と鉛筆で確認できる単純な誤り検出を加える
- 紙治具にはシード固有の秘密情報を持たせない
- ワッシャー寸法、語数、物理配置、工具などを用途に応じて応用できるようにする

## 現在のリファレンス実装

このリポジトリで現在配布する実寸資料は、次の構成を基準例として作成しています。

- DIN 9021相当 M8平ワッシャー
- SUS304 / A2ステンレス
- 外径 **24.0mm**
- 内径 **8.4mm**
- 厚さ **2.0mm**
- 打刻された1面 = 1単語
- リファレンス構成：**12単語 = 7枚**

現在の7枚構成では、1枚目と7枚目は片面だけに打刻し、その間の5枚は両面に打刻します。ボルトに通して保管するときは、1枚目と7枚目の**何も刻印していない面を外側**へ向けます。これにより、組み上げた状態では外から点字状の打刻が直接見えないようにできます。

この7枚構成は、符号化方式そのものの必須条件ではなく、物理的な組み方の一例です。製作者が別の枚数や積み方を選んでも構いません。

ワッシャー寸法や12単語という構成も、この方式そのものの必須条件ではありません。現在の資料を作る際に採用したリファレンス実装です。

別のワッシャー寸法、語数、配置、工具へ応用することもできます。その場合は、候補点の位置・治具寸法・復元規則などを用途に合わせて再設計し、実寸と復元可能性を独立に検証してください。

## 1面の情報

その面を正面に向け、**開始兼SETから時計回り**に読みます。

```text
開始兼SET | 語順2桁 | BIP39番号4桁 | CHECK
```

8ブロック構成です。

1. 開始兼SET
2. 語順 十の位
3. 語順 一の位
4. BIP39 千の位
5. BIP39 百の位
6. BIP39 十の位
7. BIP39 一の位
8. CHECK

## 語順

現在のリファレンス実装では、ニーモニック内の位置を2桁で記録します。

```text
01 ... 12
```

本プロジェクトでは「語順」という用語に統一します。

## BIP39番号

BIP39 Englishの単語表を**1始まり**で扱います。

```text
0001 = abandon
0002 = ability
...
2048 = zoo
```

BIP39内部で使われる0始まり11bit indexとは異なる、人間向けの番号です。

## 4点式点字数字

数字0〜9は標準点字数字の形を使い、上4点だけを利用します。数字専用領域なので数符は記録しません。

**● = 打刻あり / ○ = 候補位置**。上段はワッシャーの外側、下段は内側です。

![点字数字0-9](images/braille-digits-0-9.svg)

## 開始兼SET

開始位置とセットIDを1つのマーカーに統合します。

現在のリファレンス実装では、中心線上の固定点を次の位置に置きます。

- 外側固定：**r=10.0mm**
- 内側固定：**r=6.4mm**

SET候補：

- 左：**r=8.4mm / -10°**
- 右：**r=8.4mm / +10°**

標準運用：

- **A = 右だけ**
- **B = 左だけ**
- 左右両方 = 標準仕様では予備 / 無効
- 左右なし = 標準仕様では予備 / 無効

## CHECK

CHECKはBIP39番号4桁だけを対象とした単純mod 10です。

SETと語順は含めません。

例：

```text
BIP39番号 2048
2 + 0 + 4 + 8 = 14
CHECK = 6
14 + 6 = 20
```

復元時にBIP39番号4桁とCHECKを足し、合計が10の倍数ならCHECK上は正常です。

CHECKは**誤り訂正ではなく誤り検出**です。1数字だけが別の数字へ変わった場合は検出できますが、複数の誤りが相殺される場合などは見逃すことがあります。

## 打刻

現在のリファレンス実装では、実寸紙治具の上から直接センターポンチで打刻します。

1. PDFを **100% / 実際のサイズ / 拡大縮小なし** で印刷する
2. 50mm確認線を測って印刷倍率を確認する
3. 使用する治具に対応したワッシャーと位置合わせする
4. 必要な候補位置だけを紙治具越しに直接打刻する
5. 治具を外して内容を目視確認する
6. そのワッシャーに2単語目を記録する場合は、裏面も同様に打刻する

## 復元概要

現在のリファレンス配置では、次の順序で復元します。

1. 読む面を正面に向ける
2. 上下固定点を持つ開始兼SETを見つける
3. 右だけならA、左だけならB
4. 時計回りに読む
5. 語順2桁を読む
6. BIP39番号4桁を読む
7. CHECKを読みmod 10を確認する
8. 1始まり番号からBIP39 Englishへ変換する
9. 打刻された各面を語順で並べる
10. 復元したニーモニックを独立に最終確認する

7枚のリファレンス構成では、外側を向いた2つの無刻印面は意図的なものです。単語の欠落を意味しません。

## 注意点

- これは物理バックアップ方式であり暗号化ではありません。
- 必要なワッシャーを読める人はニーモニックを復元できます。
- 外側の無刻印面は、組み上げた状態で打刻を直接見えにくくするだけであり、セキュリティ境界ではありません。
- mod 10はすべての複数誤りを検出できるわけではありません。
- SETと語順は各面のCHECK対象外です。
- 実際に打刻する前に、PDFの実寸・治具・打刻方法を必ず検証してください。
- このリポジトリで配布するPDFや寸法は、現在のリファレンス実装用です。別のワッシャー寸法、語数、配置、工具へ応用する場合は、治具と復元手順を再設計して検証してください。
